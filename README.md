# 🥕 냉장고 구조대 (Save My Fridge)

> **"버리기 전에, 한 끼 더."**  
> 냉장고 속 남은 재료를 입력하면 지금 만들 수 있는 요리를 추천하고, 어떤 재료를 먼저 먹어야 하는지 알려주며, 올바른 보관법까지 제공함으로써 가정에서 발생하는 음식물 쓰레기를 줄이는 대학생 SDGs 실천 프로젝트 웹서비스입니다.

---

## 🌍 SDGs(UN 지속가능발전목표)와의 연계

본 서비스는 단순한 레시피 모음 사이트가 아니라, **가정 내 식재료 낭비 방지를 통한 지속가능한 소비 실천**을 지원합니다.

- **🎯 SDG 12: 책임감 있는 소비와 생산 (Responsible Consumption and Production - 핵심 목표)**
  - 필요한 만큼 소비하고 이미 구매한 식재료를 끝까지 섭취하여 폐기물을 원천 감소
- **🌾 SDG 2: 기아 종식 (Zero Hunger - 보조 축)**
  - 식량 자원의 소중한 가치를 재조명하고 낭비 없는 식생활 문화 정착
- **🌱 SDG 13: 기후변화 대응 (Climate Action - 보조 축)**
  - 식품의 생산·운송·보관·폐기 과정에서 발생하는 온실가스(메탄, 이산화탄소) 배출 억제

---

## ✨ 핵심 기능

1. **식재료 스마트 입력 & Autocomplete**
   - 50종 이상의 기본 식재료 자동완성 검색 및 원클릭 Quick Add (+계란, +대파, +양파 등)
   - 구매 시기(오늘, 1~2일 전, 3~5일 전, 1주 이상, 잘 모르겠어요) 및 보관 형태(냉장, 냉동, 실온) 맞춤 등록
2. **🧊 내 냉장고 시각화 보관함**
   - 현재 보관 중인 재료 수량, 보관 상태 칩, 수정/삭제 기능 실시간 연동
3. **⏰ "먼저 구조해주세요!" 우선순위 분석**
   - 구매 시기, 보관 상태, 식재료별 부패 민감도를 종합 판별하여 🔴 먼저 확인 / 🟡 가능한 빨리 사용 / 🟢 비교적 여유 있음으로 3단계 분류
   - 단정적 식품 안전 판정 금지 및 실천 안전 수칙 가이드 배너 제공
4. **🍳 지능형 레시피 추천 엔진 (36종 레시피)**
   - 🥇 바로 만들 수 있어요 / 🥈 하나만 더 있으면 돼요 / 🥉 비슷하게 만들 수 있어요
   - 우선 소비 식재료 자동 하이라이트 배너 ("🥛 우유를 먼저 활용해보세요!")
   - 결과 부재 시 "하나만 더 있으면 만들 수 있어요" 지능형 식재료 추천
5. **🧹 "냉장고 털기 (Sweep Mode)"**
   - 보유한 식재료를 한 번에 가장 많이 소진할 수 있는 요리 최우선 추천 (냉장고 활용도 % 표시)
6. **📖 식재료 보관 가이드 (27종 상세 데이터)**
   - 실시간 검색을 통한 올바른 보관법, 장기 보관 팁, 활용 요리 제안
7. **🎉 요리 완료 및 재료 차감 (구조 완료 워크플로우)**
   - "이 레시피로 요리했어요!" 클릭 시 실제 사용한 재료 선택 및 냉장고 수량 차감
   - 축하 Confetti 팡파레 파티클 애니메이션
8. **📊 나의 구조 기록 (LocalStorage 영구 보존)**
   - 만든 요리 수, 활용한 재료 수, 구조 성공 횟수, 연속 실천 일수(Streak) 집계
   - 최근 요리 히스토리 기록 (새로고침해도 영구 유지)
9. **🔍 오늘의 작은 미션**
   - 날짜별 일상 속 작은 냉장고 관리 미션 제시 및 완료 토글

## 🛠️ 기술 스택

- **Frontend**: HTML5 (Semantic Markup), CSS3 (Modern Flexbox/Grid, CSS Variables), Vanilla JavaScript (ES6+ Modules)
- **Data Persistence**: 브라우저 `localStorage` (외부 백엔드/API 의존 없이 100% 독립 실행)
- **Deployment**: GitHub Pages 배포 지원 (빌드 과정 없이 즉시 배포 가능)
- **Aesthetics & UX**:
  - 컬러 팔레트: Fresh Green (`#4F8A62`), Cream (`#FFFDF7`), Warm Yellow (`#F4C95D`), Tomato (`#E9785D`)
  - 타이포그래피: Pretendard 웹폰트 (한국어 가독성 최우선)
  - 반응형 디자인: 데스크탑(2~4열 그리드) ~ 모바일(1~2열 그리드, 햄버거 메뉴, 플로팅 CTA) 완벽 지원 (가로 오버플로우 0%)
  - 접근성(A11y): 시맨틱 태그, 포커스 아웃라인, 키보드 탐색 및 ESC 모달 닫기 지원

## 🚀 로컬 실행 방법

브라우저 보안 정책상 ES 모듈(`type="module"`)을 로드하려면 정적 웹 서버 환경에서 실행하는 것이 권장됩니다:

```bash
# 1. npx serve 사용 시
npx -y serve ./

# 또는 Python 내장 서버 사용 시
python -m http.server 3000

# 또는 VS Code "Live Server" 확장 프로그램으로 index.html 실행
```
